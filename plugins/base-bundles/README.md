# Base bundles

Base sequence preparation, Flashblocks simulation guidance, and Blink attribution
request construction. Attribution does not provide atomic sequencer submission.
Independent of the Ethereum, Unichain, and filler skills; no signer or bot.

```
/plugin marketplace add asyncswap/skills
/plugin install base-bundles@asyncswap
```

For Codex, install the complete [skill directory](skills/base-bundles/SKILL.md)
with its references. Offline examples use `@asyncswap/jsonrpc@0.4.16`.
